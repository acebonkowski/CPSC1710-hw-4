# HIGH LEVEL OVERVIEW

We want to write Python code that generates new text of 188 character-length one character at a time, after learning from a small training text, across 4 different temperatures. The code should:

1) Take a tiny training text (the 10 "I like ..." sentences listed at the bottom).
2) Define and train a small RNN as a Keras Sequential model with 3 layers (Embedding, LSTM, Dense). The LSTM layer reads characters in order and keeps a continuously updated memory. The model learns to predict the next character after reading the previous 40 characters (= sequence length).
3) Generate 180 new characters, starting from the seed "I like ", once for each of four temperatures: [0.1, 0.5, 0.7, 1.0]. For every new character, the model reads the latest 40 characters, picks the next one, adds it to the text, and slides the 40-character window forward by one character.

Use the random seed SEED = 1710 so that runs are reproducible.


# BEHAVIOR OF THE DEMO

Step 1: Import numpy (as np) and tensorflow (as tf). Define SEED = 1710 and, if SEED is not None, call tf.keras.utils.set_random_seed(SEED). Also create a separate NumPy random generator, rng = np.random.default_rng(SEED), which is used later to pick characters at random.

Step 2: Glue the 10 training sentences together into one string called text, with a newline character between them. Find the unique characters, sort them into a list called chars and create two dictionaries: stoi (character to integer id) and itos (integer id to character). Print the text length and the vocabulary list.

Step 3: Define sequence length at 40 and step size at 1. Slide a 40-character window over the text, one character at a time. For each window, store the 40 character ids and the id of the character right after the window. Convert both containers into NumPy int32 arrays and print the number of training samples.

Step 4: Define the Keras Sequential model with 3 layers:
  - Embedding: gives each of the 22 characters a vector of 32 numbers.
  - LSTM: reads the 40 character vectors in order and keeps a memory of 128 numbers. It returns only its final memory, after the 40th character.
  - Dense: turns those 128 numbers into 22 raw scores (logits), one per possible next character.
  - Compile the model with the Adam optimizer (learning rate 0.01), and the loss SparseCategoricalCrossentropy 

Step 5: Train the model with a batch size of 64 across 20 epochs at zero verbose and print the final loss.

Step 6: Define 3 helper functions:
  1) sample_logits: picks the id of the next character. If temperature <= 0, take the highest score. Otherwise divide the scores by the temperature, convert them to probabilities, and randomly choose an id using rng and those probabilities.
  2) next_char_probabilities: pads the seed on the left with spaces to 40 characters, converts the last 40 characters to ids (unknown characters become id 0), feeds them to the model as a batch of one question to get the 22 scores, turns the scores into probabilities (softmax of scores divided by temperature, or 100% on the top character if temperature <= 0), and returns the top 5 (character, probability) pairs, highest first.
  3) generate: pads the seed to 40 characters, then repeat the process n times: get the scores from the model for the current 40-character context, pick the next character with, add it to the output, and update the context by dropping its oldest id and adding the new one. Returns the output as a string.

Step 7: For each temperature in [0.1, 0.5, 0.7, 1.0]:
  - print a subheader with the temperature of the run
  - print the top 5 character probabilities for the first generated character after the seed "I like ",
  - print the text generated by generate with seed "I like ", not exceeding 188 characters.
